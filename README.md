# 🚀 Portfólio Pessoal - Jean Guedes

Aplicação web moderna com foco em **experiência visual cinematográfica**, navegação fluida e apresentação profissional de projetos.

Este projeto foi desenvolvido para destacar habilidades em desenvolvimento front-end, animações avançadas e organização de conteúdo técnico.

---

## ✨ Demonstração

🔗 Acesse o projeto:
👉 https://jeanguedesdev.com.br/

---

## 🧠 Sobre o Projeto

Este portfólio foi inspirado em experiências imersivas como o site da DVLPR, trazendo:

* Navegação por **scroll cinematográfico**
* Transições suaves entre seções
* Seção de projetos com **scroll horizontal animado**
* Layout responsivo com adaptação para mobile
* Alternância de tema **dark/light com animação suave**

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* GSAP (GreenSock Animation Platform)
* ScrollTrigger
* Lenis (smooth scroll)

---

## 🎯 Funcionalidades

### 🖥️ Desktop

* Scroll por seções (full-page)
* Transições com easing avançado
* Navegação lateral com indicador de progresso
* Projetos com navegação horizontal animada

### 📱 Mobile

* Layout adaptado para rolagem vertical
* Projetos exibidos em lista (melhor usabilidade)
* Interface otimizada para telas menores

### 🌗 Tema Dinâmico

* Alternância entre tema claro e escuro
* Transições suaves de cores
* Elementos adaptativos (ícones, botões, textos)
